Pill action button; use `primary` (near-black) for the main CTA, `accent` (cobalt) for product-internal primaries, `inverse`/`inverse-outline` on dark sections.

```jsx
<Button variant="primary" size="lg">Start free</Button>
<Button variant="secondary">View pricing</Button>
```

Sentence case, verb-first, 1–3 words. One primary per view.
