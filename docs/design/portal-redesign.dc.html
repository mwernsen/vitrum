Where everything lives — one switcher, one home each

Fair callout: the dock tabs and the side rail were doing the same job. Fixed — the activity rail is the only panel switcher; clicking an icon swaps what's docked. No tabs. Every roadmap feature now has exactly one home, so nothing piles into the inspector again. The map below shows what each region owns; 3a–3e detail each rail panel.

What each region owns
1
Top bar — the whole document. Name & save state, the Design/Cartoon/Render/Light view switch, undo/redo, export, account. Global, never feature-specific.
2
Readiness strip — status, not steps. Geometry · Glass · Checks · Outputs, each a live state you can jump to in any order. Replaces linear stages.
3·4
Activity rail + dock — every feature panel. The rail is the single switcher; the dock shows the active one: Layers, Glass, Rules, Make, Versions. This is where new features land.
5
Canvas + floating tools — making marks. The document and its overlays; drawing tools float over it so they follow the cursor, not a fixed edge.
6
Inspector — the current selection only. Properties of what's selected (segment, piece, guide). Empty selection ⇒ collapses. No feature dumps its panel here anymore.
7
Status bar — the viewport. Cursor coordinates, grid/snap, zoom, units. Overlay toggles that were scattered here move into the Layers panel.
